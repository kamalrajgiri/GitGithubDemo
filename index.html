Welcome to Git and GitHub! This is a simple HTML page to demonstrate the use of Git and GitHub for version control and collaboration. You can edit this file, commit your changes, and push them to your GitHub repository. Happy coding!

git branch creates a new branch in the repository. git switch moves to a different branch.

  • git branch : creates a new branch
  • git switch : moves to a different branch
  • git switch -c : creates a new branch and switches to it
  • git merge : merges changes from one branch into another
